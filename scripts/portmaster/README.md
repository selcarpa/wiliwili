## Controls

| Button | Action |
|--|--|
| A | Confirm |
| B | Back |
| X | Toggle subtitle |
| Y | Toggle danmaku |
| D-Pad | Navigate |
| Left Stick | Navigate / Seek |
| Right Stick | Volume |
| Start | Pause / Menu |
| Select | Switch subtitle track |
| L1 | Previous episode |
| R1 | Next episode |
| L2 | Speed down |
| R2 | Speed up |
| L3 | Toggle fullscreen |
| R3 | Toggle OSD |

## Compile

```shell
cd wiliwili
bash scripts/portmaster/run.sh
```
